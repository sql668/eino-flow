> 依赖顺序：本组是第 2 组能真正跑通的前提（第 2 组可先用测试替身开发，但端到端必须等本组完成）。

- [ ] 6.1 openai 兼容适配器支持工具：请求带 `tools`、解析响应与流式分片的 `tool_calls`（单测：非流式返回工具调用、流式分片参数能拼成完整 JSON）
- [ ] 6.2 Ollama 适配器支持工具：按 `/api/chat` 的 `tools` 传参并解析 `tool_calls`，去掉"暂不支持工具调用"的硬报错（单测：工具调用能被解析成 `schema.Message.ToolCalls`）
- [ ] 6.3 模型不支持工具时返回明确错误（单测：不支持时错误可判定，且**不**返回退化回答）
- [ ] 6.4 resolver 提供"按能力取模型"的入口，调用方不感知厂商（单测：取工具模型时走的是同一套解析与缓存）
- [ ] 6.5 `make backend-check` 全绿
